# Mathematical Knowledge Model

Represent knowledge as data separate from algorithms. Record types include:
- axiom / postulate
- definition
- theorem / lemma / corollary
- identity
- equation / inequality
- conjecture / counterexample
- proof
- algorithm
- mathematical term
- theory / field / subfield

Suggested fields: stable ID, title, statement, symbols, domain, assumptions, prerequisites, proof status, proof sketch, equivalent forms, examples, citations/references, related records, and verification tests.
